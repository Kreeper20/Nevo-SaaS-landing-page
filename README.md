# Nevo — AI Feedback Intelligence

Nevo is an AI-powered feedback intelligence platform that helps teams collect, analyse, and act on user feedback — turning raw responses into actionable insights automatically.

This is a front-end concept and landing page built as a portfolio project.

## Live Demo
[View Live →]((https://nevo-saas-landing-page.vercel.app))

## Built With
- React + TypeScript
- Vite
- Tailwind CSS
- Instrument Serif + DM Sans

## Features
- Full landing page with hero, features, pricing, FAQ, and integrations sections
- Pricing toggle (monthly / annual)
- Integrations grid
- Dark theme design system
- Fully responsive

## Running Locally
```bash
git clone https://github.com/Kreeper20/nevo
cd nevo
npm install
npm run dev
```

## Notes
This is a portfolio/concept project — not a live product. Built to demonstrate UI design, component architecture, and design system implementation in React + Tailwind.
